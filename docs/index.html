Start from a demo

Two complete examples, each an event stream with the views by-page and by-time and the LDIO pipeline that feeds it:

  • Sensor observations, modelled with SOSA/SSN, with sample data sent through the pipeline;
  • Parking occupancy of the car parks of Ghent, polled live from the open data of the city and mapped to Mobivoc, after the OpenLDES onboarding example.

Pick them when you start a local LDES server or LDIO, or start a new event stream from one.

Try it without servers

Demo mode runs on sample data in the browser, to explore LDES-admin without any server; production mode manages real LDES servers and LDIOs. The switch sits in the top bar. Light and dark themes included.

Without a backend, the frontend starts in demo mode by itself: everything, including the sandbox, works on sample data that behaves like the real thing.
